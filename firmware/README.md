# firmware/

Phần mềm nhúng — firmware ESP32 cho Robot Charge Controller.

## Cấu trúc

| Thư mục | Chức năng |
|---|---|
| `include/` | Header file công khai |
| `src/` | Mã nguồn chính |
| `lib/` | Thư viện và module nội bộ |
| `test/` | Kiểm thử phần mềm |

Công cụ phát triển: Visual Studio Code, PlatformIO hoặc ESP-IDF.
